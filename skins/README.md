# Skins

Add or change a skin:

1. Save a standard 64x64 Minecraft skin PNG as `skins/<ExactInGameName>.png`.
   The name is case-sensitive: `Steve` and `steve` are different files.
2. Run `scripts\publish.ps1 "add skin"`.

Players see the new skin after restarting the game (the skin cache may take a few minutes).
Skins in this folder override the normal Microsoft account skin; players with no file here keep their normal skin.
